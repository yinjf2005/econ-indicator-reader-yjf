## §A · S1 指标归位

### §A.1 案例 1 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **四问**：基期是否含异常（上年同期低基数？）/ 环比是否季调 / 不年化 / 名义实际 | 同比受基期直接影响——**基期异常是翘尾高估的根源** |
| 2 | **同比看趋势、环比看边际** | 二者背离的标准解读：**趋势尚未转向，但边际已在收缩** |
| 3 | **翘尾 vs 新涨价拆解** | `+0.7% + (−0.2%) = +0.5%` ⇒ **新涨价实为 −0.2%，结论从"通胀"翻转为"新增动能为负"** |
| 4 | **核心 vs 整体裂口** | 核心 +0.8% 更高 ⇒ 波动来自**食品项**；可用商务部食用农产品价格指数、农业部批发 200 指数周频验证 |
| 5 | **基期轮换** | 跨基期比较须重估权重，**不得**直接连序列 |

### §A.2 案例 2 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **归位关系**：PPI 是**领先**指标（生产资料价格），CPI 偏**滞后** | 剪刀差（PPI − CPI）是**关系型输入**，须先判关系类型（传导 / 同步 / 共同因子） |
| 2 | **三因子拆解**：企业利润 = 量 × 价 × 利润率 | PPI 改善 → 上游盈利改善；终端需求弱则中下游无法转嫁 ⇒ **上游涨、下游不涨** |
| 3 | **交叉验证**：PMI 出厂价分项 → PPI 环比（历史 R²≈0.81） | 月内可用螺纹、原油、铜价、南华工业品指数推 PPI |
| 4 | **传导条件**：需要**终端需求配合**，需求疲弱时传导系数≈0 | 此时"剪刀差扩大"是**利润再分配**信号，**不是**通胀前兆 |
| 5 | **政策含义**：稳物价看 CPI，稳工业利润看 PPI 与量价利润率三因子 | 目标不同，看的数不同 |

### §A.3 物价领域通用工具表

| 工具 | 回答什么 | 领先/滞后 |
|---|---|---|
| 翘尾 / 新涨价拆分 | 同比里有多少是"去年欠的" | 翘尾年初可算，滞后 |
| 核心 CPI（剔食品能源） | 趋势性通胀 | 同步 |
| PMI 出厂价分项 | PPI 环比的先行估计（R²≈0.81） | **领先** |
| 商务部食用农产品指数 | 食品项周频验证 | 同步偏领先 |
| 农业部批发 200 指数 | 食品项周频验证 | 同步偏领先 |
| 南华工业品 / 螺纹 / 原油 / 铜 | PPI 月内推演 | 领先 |

## §B · S2 读数四问详审

| 四问 | 本卡答案 | 陷阱 |
|---|---|---|
| **基期** | 同比基期决定翘尾高低；上年同期异常会**抬高或压低**本期同比 | 跨基期轮换须重估权重 |
| **季调** | CPI 环比**通常未季调**（J3） | 拿未季调环比单独定趋势是错的 |
| **年化** | 月度同比**不年化** | +0.5% 不是折年率 |
| **名义实际** | 价格指数**无名义实际之分**，比较时须把**其它量**统一到实际 | 拿 CPI 跟名义收入直接比是错的（J4） |

**发布纪律**：翘尾在**年初可精确测算**，不随月度修正；新涨价才是当期信息。看到"同比 +0.5%"先问一句"这里面多少是翘尾"——这是物价领域第一纪律。

## §C · S3 结构归位

**L2 语义（必标字段，v2.3 记入口径）**

| 字段 | 场景 1（CPI） | 场景 2（PPI） |
|---|---|---|
| `stock_flow` | **存量**（价格水平） | **存量**（价格水平） |
| `nominal_real` | **名义**（价格本身即名义量） | **名义** |
| `time_frame` | **月度** | **月度** |
| `endogeneity` | 通胀**内生**（货币 + 需求共同决定） | 出厂价**内生**，受国际大宗（外生）传导 |

**结构归位三步**

1. **拆结构**：总指数 = Σ（分项指数 × 权重）。CPI 拆食品/能源/核心，PPI 拆生产资料/生活资料。
2. **定层次**：整体 → 核心/分项 → 翘尾/新涨价。三层读完才能说"动能"。
3. **看两轨**：水平（同比）+ 边际（环比）；价格还要注意**滞后贡献**（翘尾）这条特殊腿。

## §D · S4 双轨解码与分解

### §D.1 翘尾/新涨价恒等式（J1 依据）

$$g_{\text{同比}} = g_{\text{翘尾}} + g_{\text{新涨价}}$$

| 构成 | 贡献（pp） | 性质 |
|---|---|---|
| 翘尾 | +0.7 | 滞后（上年涨价对本年的传导） |
| 新涨价 | −0.2 | 当期 |
| 合计 | **+0.5** ✓ | 闭合 |

> **判定**：不拆翘尾就把 +0.5% 读成"通胀在扩张"，是把**滞后贡献**当成**当期动能**——方向读反（J1 改写为"动能为负"）。

### §D.2 核心与整体的裂口（J2 依据）

| 口径 | 同比 | 含义 |
|---|---|---|
| 整体 CPI（含食品能源） | +0.5% | 居民**体感**通胀 |
| 核心 CPI（剔食品能源） | **+0.8%** | **趋势性**通胀 |
| 裂口 | **−0.3pp** | 核心更高 ⇒ **食品项在拖累整体** |

### §D.3 传导条件与剪刀差（J5 依据）

| 项 | 值 |
|---|---|
| PPI 同比（起点） | −2.0% |
| PPI 同比（本期） | −0.3% |
| CPI 同比（本期） | +0.2%（走低） |
| 剪刀差（PPI − CPI） | 由 +0.2 变为 **−0.5** |

> ⚠ **表述纪律（v2.3 升级改错）**：原案"剪刀差收窄"未定义剪刀差口径。PPI 与 CPI **走向相反**（PPI 上行、CPI 下行），严格写法须**先给数值**再定性：裂口由 +0.2 变 −0.5 属**反向扩大**。写"收窄"是把二者当同一根尺子的两端。**不得**在不定义口径的情况下定性。

**传导两条件**（缺一则不成立，J5 因此落"待验证假设"）

| 条件 | 需要的证据 | 本卡状态 |
|---|---|---|
| 终端需求配合 | N4（社零 / PMI 新订单） | **缺** |
| 中下游定价能力 | N3（产能利用率 / 出厂−购进价差） | **缺** |

## §F · S6 预期层与预期差

**结论：本卡不算 surprise，显式声明"无共识可得"。**

| 项 | 值 |
|---|---|
| 是否有公开共识 | **无**（教学构造，N5 未补） |
| 是否算 surprise | **否** |

**方法要点（教学用）**：真实卡里 `surprise = 实际 − 共识`，且 surprise 只对**偏离**定价。物价卡尤其容易犯的错是**拿前值当共识**（"比上月低 0.3 个点，所以低于预期"）——前值不是预期。**缺靶子就声明缺。**

**决策含义（条件式，非投资建议）**：若 <补齐 N5 共识与前值> 则 <可算 surprise 与位移>；若 <仅得水平> 则 <维持"无共识"声明，D 闸门恒为否>。

## §H · 对照与反例

| # | 反例 | 为什么错 |
|---|---|---|
| H-1 | "CPI 同比 +0.5% ⇒ 通胀起来了" | 没拆翘尾；新涨价是 **−0.2%** |
| H-2 | "CPI 环比 −0.2% ⇒ 通缩加剧" | 环比**未季调**，且不能单独定趋势 |
| H-3 | "核心 CPI 更高 ⇒ 通胀更严重" | 核心高是**剔除波动项**后的趋势读数，整体高才是体感；两者说明的不是一回事 |

## §J · 可复现性

```python
# 翘尾 / 新涨价恒等式（J1 依据）
g_qiwei, g_new = 0.7, -0.2
g_yoy = round(g_qiwei + g_new, 2)
assert g_yoy == 0.5                     # +0.5%

# 核心与整体裂口（J2）
print(round(0.8 - 0.5, 2))              # 0.3pp → 核心更高 ⇒ 食品拖累

# 剪刀差（J5，先给数值再定性）
g_ppi, g_cpi = -0.3, 0.2
print(round(g_ppi - g_cpi, 2))          # -0.5 ← 由 +0.2 变 -0.5，属反向扩大
```

**算式**（两侧量纲一致：翘尾 + 新涨价 = 同比，单位均为百分点）

$$g_{\text{同比}} = g_{\text{翘尾}} + g_{\text{新涨价}},\qquad
\text{剪刀差}=g_{\text{PPI}}-g_{\text{CPI}}$$
