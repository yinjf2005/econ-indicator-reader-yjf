## §A · S1 指标归位

### §A.1 案例 1 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **误区⑩：狭义赤字 ≠ 实际赤字** | 实际赤字 = 一般公共预算赤字 + 从政府性基金/结转结余**调入** + 专项债等广义工具形成的支出 |
| 2 | **四本账**：一般公共预算、政府性基金、国有资本经营、社会保险基金 | 看积极财政力度须**合并看广义赤字** |
| 3 | **土地出让金归政府性基金** | 其波动直接影响可支配财力；房地产下行期基金收入下滑会削弱支出能力，**即便赤字率不变** |
| 4 | **财政存款 ≠ 闲置资金** | 季末支出释放流动性是**调度节奏**，不能当"还有钱没花" |
| 5 | **交叉验证** | 专项债发行进度、城投净融资、基建实物工作量（水泥、挖掘机、沥青开工率） |

### §A.2 案例 2 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **归位：螺旋样态** | 加码 → 资金到位 → 项目开工 → 数据改善 → 政策退坡 → 数据回落 → 再加码 |
| 2 | **口径** | 固投完成额 ≠ 固定资本形成总额；基建有广义/狭义之分，口径调整（如新基建纳入）会**造成序列断裂**，前后不可直接连 |
| 3 | **资金来源四分法** | 预算内、政府性基金、专项债、城投等；专项债放量可能用于**置换隐性债务或补充中小银行资本金** |
| 4 | **物理量体检** | 水泥产量、挖掘机销量、沥青开工率、螺纹钢表观消费——施工强度**先行 2—4 周** |
| 5 | **修订与基准** | 投资数据年度修订幅度较大，季末与年初数据不可直接比较 |

### §A.3 财政领域通用工具表

| 工具 | 回答什么 | 口径 |
|---|---|---|
| 狭义赤字率 | 一般公共预算缺口 | 单账 |
| **广义赤字率**（四本账合并） | **真实财政力度** | 全账 |
| 政府性基金收支（含土地出让金） | 可支配财力与地产周期 | 第二本账 |
| 专项债资金用途明细 | 是新增项目还是还旧账 | 资金端 |
| 城投净融资 | 隐性扩张渠道 | 表外 |
| 水泥 / 挖掘机 / 沥青开工 | **实物工作量**（先行 2—4 周） | 物理量 |

## §B · S2 读数四问详审

| 四问 | 本卡答案 | 陷阱 |
|---|---|---|
| **基期** | 预算口径基期是**上年同期决算数** | 不得拿**预算数**与**决算数**直接比（预算数含假设） |
| **季调** | 财政收支按月报，无季节调整问题；⚠ 但**存款余额**有真实季节（季末支出节奏） | 把存款余额的季节波动当"有钱没花"（J4 已声明） |
| **年化** | 年度数**不年化** | 赤字率不是折年率 |
| **名义实际** | 财政收支**名义**（未剔价格） | 与产出侧（实际 GDP）比较时须声明口径差异 |

**发布纪律**：评价财政力度看**广义赤字 + 实物工作量**，不看单一赤字率——这是财政领域第一纪律。

## §C · S3 结构归位

**L2 语义（必标字段，v2.3 记入口径）**

| 字段 | 场景 1（赤字） | 场景 2（专项债/基建） |
|---|---|---|
| `stock_flow` | 一般公共预算收支为**流量**；赤字为**差额** | 专项债为**融资流量**；基建投资为**形成流量** |
| `nominal_real` | **名义**（未剔价格） | **名义** |
| `time_frame` | **年度** | **季度** |
| `endogeneity` | 财政政策**外生**（主动变量）；经济周期**内生** | 投资需求**内生**；政策加码**外生** |

**结构归位三步**

1. **拆结构**：赤字 = 狭义 + 调入 + 专项债等广义工具；投资 = 资金到位 → 形成 → 实物工作量。
2. **定层次**：看**全口径**（四本账）不看单账；看**形成端**不看资金端。
3. **看两轨**：账上（赤字率、发行进度）+ 地上（水泥、挖掘机、沥青）。

## §D · S4 双轨解码与分解

### §D.1 狭义→实际的口径桥（J1 依据）

$$\text{口径差}=\frac{0.5}{130}=0.3846\%\approx0.38\text{pp},\qquad \text{实际赤字率}=3.00\%+0.38\%=3.38\%$$

$$\text{实际赤字}=3.9\text{万亿}+0.5\text{万亿}=4.4\text{万亿}$$

| 项 | 金额（万亿） | 占 GDP |
|---|---|---|
| 狭义赤字 | 3.9 | 3.00% |
| 调入（政府性基金/结转结余） | +0.5 | +0.38pp |
| 实际赤字 | **4.4** | **3.38%** |

> **判定**：0.38pp 是**口径差**（J1）。把 3.0% 当财政力度，等于假设那 0.5 万亿元不存在。

### §D.2 资金端 vs 形成端（J5 依据）

| 端 | 指标 | 本期 |
|---|---|---|
| 资金端 | 专项债发行同比 | **+40%** |
| 形成端 | 基建投资同比 | **+3%** |
| 裂口 | — | **37pp** |

**四因素**（缺一不可判"空转"）

| 因素 | 说明 | 本卡证据 |
|---|---|---|
| **时滞** | 投放到形成通常 **1—2 季** | 缺 N4 |
| **资金用途** | 可能用于置换隐性债务 / 补充资本金，**非新增项目** | 缺 N3 |
| **口径** | 固投完成额 ≠ 固定资本形成总额 | 口径已说明，未补数 |
| **口径调整** | 广义/狭义基建切换造成序列断裂 | 缺 N5 |

> **判定**：37pp 裂口在**时滞期内是常态**；判"空转"必须等 N4 物理量也走平之后（J5 落"待验证假设"）。

## §H · 对照与反例

| # | 反例 | 为什么错 |
|---|---|---|
| H-1 | "赤字率没提 = 财政没加力" | 漏了调入与广义工具（J1/J2 已改写） |

| H-3 | "专项债放量 + 基建弱 = 资金空转" | 缺时滞与用途证据前**不能判**（J5） |

## §J · 可复现性

```python
# 狭义 → 实际的口径桥（J1）
gdp, deficit狭义, transfer = 130.0, 3.9, 0.5
gap_pp  = round(transfer / gdp * 100, 2)        # 0.38 pp
actual  = round(deficit狭义 + transfer, 2)      # 4.4 万亿
print(round(actual / gdp * 100, 2))             # 3.38%

# 资金端 vs 形成端裂口（J5）
print(40 - 3)                                    # 37 pp（须先过时滞与用途两关）
```

**算式**（两侧量纲一致：调入额 ÷ GDP = 赤字率口径差）

$$\text{实际赤字}=\text{狭义赤字}+\text{调入},\qquad
\text{实际赤字率}=\text{狭义赤字率}+\frac{\text{调入}}{\text{GDP}}$$
