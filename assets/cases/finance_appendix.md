## §A · S1 指标归位

### §A.1 案例 1 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **只对偏离定价，不对水平定价** | `surprise = 实际 − 共识 = 9.6% − 9.3% = +0.3pp` |
| 2 | 市场反应由「偏离 + 已定价程度 + 离散度」共同决定 | 连续三月超预期 ⇒ **惊喜被花光** |
| 3 | **看结构而非总量** | 超预期若来自政府债与票据冲量、企业中长贷走弱 ⇒ 总 surprise 正、质量 surprise 负 |
| 4 | **交叉验证**：债（通胀与增长预期）/ 汇（相对利差）/ 商品（实物需求）/ 股（盈利预期） | 股债反向 = 定价"增长质量存疑 + 宽松预期" |
| 5 | **敏感度** | 社融在**债市**敏感度高；股市更看 ISM / 首申 / 零售等需求端先行指标 |

### §A.2 案例 2 五步推演（原案方法要点全量保留）

| 步 | 动作 | 本案例结论 |
|---|---|---|
| 1 | **春节错位**：年终奖发放、居民取现、企业存款转居民存款 | 1 月 M1 冲高、2 月跳水；**单月 M1−M2 在 1—2 月不可用** |
| 2 | **正确做法** | 看 1—2 月**平均**，或看**季调后序列** |
| 3 | **口径**：M1、M2 是**存量**指标，剪刀差是存量增速之差；**社融 ≠ M2**（范围不同） | 不得与社混为一谈；看"社融 − M2 增速差"另有所指 |
| 4 | **存量 vs 流量** | 存量看**水位**，流量看**速度**；判断资金活化要看存款**结构**（居民 vs 企业、定期 vs 活期） |
| 5 | **交叉验证** | 企业活期存款变化、票据利率、企业中长贷 |

## §B · S2 读数四问详审

| 四问 | 本卡答案 | 陷阱 |
|---|---|---|
| **基期** | 存量同比的基期是**上年同月末**（存量是时点数，不是流量累计数） | 把存量同比当"本期新增"是错的 |
| **季调** | 存量同比**未季调**；⚠ 但**判趋势要用季调后月均或两月平均**（场景 2 的关键） | 拿未季调单月剪刀差定趋势 |
| **年化** | 存量同比**不年化** | 9.6% 不是折年率 |
| **名义实际** | 社融、M1、M2 一般**只谈名义**（未剔价格） | 与其它量比较时须**统一到同口径名义** |

**发布纪律**：看到"1—2 月单月读数很惊人"，**第一件事是查是不是春节错位**——这是月度金融数据最大的假信号源。

## §C · S3 结构归位

**L2 语义（必标字段，v2.3 记入口径）**

| 字段 | 社融 | M1 / M2 |
|---|---|---|
| `stock_flow` | **存量** | **存量** |
| `nominal_real` | **名义**（未剔价格） | **名义** |
| `time_frame` | **月度**（时点观测） | **月度**（时点观测） |
| `endogeneity` | 信用扩张**内生**；央行操作与监管口径**外生** | 存款**内生**；央行操作、监管口径**外生** |

**结构归位三步**

1. **拆结构**：社融 = Σ（各分项贡献）。总量 surprise 必须落到分项才能读质量。
2. **定层次**：总量 surprise → 质量 surprise → 市场反应。三层**顺序不能颠倒**（不能拿市场反应去证明 surprise）。
3. **看两轨**：水位（存量同比）+ 速度（存量月均变化 / 流量）。

## §D · S4 双轨解码与分解

### §D.1 surprise 与质量 surprise（J1 / J2 依据）

| 层 | 值 | 说明 |
|---|---|---|
| 共识 | 9.3% | 定价基准 |
| 实际 | 9.6% | 读数 |
| **总量 surprise** | **+0.3pp** | 正的 |
| **质量 surprise** | 待定（**N1**） | 若靠政府债+票据 ⇒ **负** |
| 市场反应 | 权益跌 / 债强 | 与总量 surprise **反向** |

> **判定**：总量 surprise 正、市场跌——两者**不同轴**，不矛盾。错在"用市场反应去验证 surprise"（循环论证）。

### §D.2 存量与两种"差"（J4 依据）

| 差 | 定义 | 构成差别 |
|---|---|---|
| **M1 − M2（剪刀差）** | M1 同比 − M2 同比 | **存款**口径内部两个子口径之差 |
| **社融 − M2 增速差** | 社融存量同比 − M2 同比 | 一个**融资总量**、一个**存款总量** |

> **判定**：这两个差**口径不同、含义不同，不可混用**（J4）。把社融 − M2 增速差叫"剪刀差"是典型错名。

### §D.3 春节错位（J5 依据）

| 月 | M1 同比 | M2 同比 | M1−M2 剪刀差 |
|---|---|---|---|
| 1 月 | +5.0% | +8.0% | **−3.0pp** |
| 2 月 | −1.0% | +8.5% | **−9.5pp** |
| 落差 | **−6.0pp** | +0.5pp | **−6.5pp** |

> **判定**：M1 抖了 6.0pp 而 M2 只动了 0.5pp —— **抖在存款结构而非总量**，正是年终奖/取现/存款转手的指纹。故 1—2 月单月剪刀差在方法上**不可用**。

## §F · S6 预期层与预期差

| 项 | 值 |
|---|---|
| 共识可得性 | 场景 1 有共识（9.3%，**教学构造**） |
| 是否算 surprise | **是**（真实卡须用真实共识重算） |
| 本次 surprise | **+0.3pp** |

**surprise 五特性（教学要点）**

| 特性 | 说明 |
|---|---|
| 只对偏离定价 | 水平高低不等于市场反应强弱 |
| 已定价程度 | 连续超预期会**花光惊喜** |
| 离散度 | 机构分歧大时，均值 surprise 解释力下降 |
| 质量 surprise | 结构比总量更被定价（J2） |
| 不同轴 | surprise（预期差轴）≠ 市场反应（资产价格轴） |

**决策含义（条件式，非投资建议）**：若 <N1 显示企业中长贷走弱> 则 <质量 surprise 为负>；若 <N2 显示前两月连超> 则 <惊喜已花光>。

## §H · 对照与反例

| # | 反例 | 为什么错 |
|---|---|---|
| H-1 | "数据超预期，股市却跌 = 市场错了" | 市场定价的是**质量 surprise**，与总量 surprise 可反向 |
| H-2 | "超预期 0.3pp 所以市场反应小" | 被定价的是偏离里的结构 + 已定价程度，不是绝对值 |
| H-3 | "9.6% ⇒ 信用扩张" | 总量超预期可能来自政府债与票据冲量 |
| H-4 | "M1−M2 从 −3.0 到 −9.5 ⇒ 资金活化崩了" | **1—2 月春节错位**，单月剪刀差不可用（J5 已改写） |
| H-5 | "社融 − M2 = 剪刀差" | 两个**不同的差**，口径不同（J4） |
| H-6 | 拿单月 **未季调**存量同比定趋势 | 存量是时点数，须用季调后或两月平均 |

## §J · 可复现性

```python
# surprise（J1）
g_act, g_cons = 9.6, 9.3
surprise = round(g_act - g_cons, 2)      # +0.3 pp

# 两种“差”不可混用（J4）
m1_jan, m2_jan = 5.0, 8.0
scissors_jan = round(m1_jan - m2_jan, 2)  # -3.0
m1_feb, m2_feb = -1.0, 8.5
scissors_feb = round(m1_feb - m2_feb, 2)  # -9.5
print(scissors_feb - scissors_jan)        # -6.5 pp 落差（须先过“是否1—2月”这关）
```

**算式**（两侧量纲一致：surprise 与剪刀差单位均为百分点）

$$\text{surprise}=g_{\text{实际}}-g_{\text{共识}},\qquad
\text{剪刀差}=g_{\text{M1}}-g_{\text{M2}}$$
