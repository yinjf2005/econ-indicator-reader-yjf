## 一、十大使用误区（引数据前必读）

| # | 误区 | 对策 |
|---|---|---|
| ① | 美元/人民币计价混用：同一段切换币种致增速差约 9pp | 先声明币种；跨年汇率大变优先美元计价 |
| ② | 春节错位外推：1 月冲高 / 2 月跳水直接判趋势 | 1–2 月只看累计值，其余看季调环比 |
| ③ | 海关差额 = GDP 净出口：漏服务贸易、到岸/离岸差，高估净出口 | 用外管局国际货物与服务贸易数据近似 |
| ④ | CPI 旧基期权重套新数据：2016 与 2020 基期结构不同 | 跨基期重估权重，可用"拉动点数 ÷ 分项同比"反推 |
| ⑤ | 翘尾当新涨价：CPI 同比高就误判"新通胀" | 拆翘尾（年初可测）+ 新涨价，只看新增部分 |
| ⑥ | 社融 = M2：忽略统计范围缺口 | 看**社融 − M2** 增速差所含信息 |
| ⑦ | M1 − M2 单月判趋势：春节错位致 1–2 月失真 | 看 1–2 月平均或季调后序列 |
| ⑧ | PMI 绝对值迷思：以为"过 50 就行" | 看动能 a−b 与分项链；中国制造业长期 > 50 |
| ⑨ | 外汇占款 = 外汇储备：估值口径不同（历史成本 vs 市值） | 分开看：外汇占款看基础货币，外汇储备看家底 |
| ⑩ | 狭义赤字 = 实际赤字：漏政府性基金调入与结转结余 | 用实际赤字（含调入）评积极财政力度 |

## 二、五项跨章节口径陷阱

- **固投完成额 ≠ 固定资本形成总额**：500 万门槛、含土地购置费与旧设备购置、不含商品房销售增值与研发支出（2017–18 因研发支出纳入而背离）。
- **服务业生产指数 ≠ 三产 GDP 同比**：仅覆盖市场性活动，短期领先约半年，宜作方向参考。
- **居民中长期贷 ≠ 纯房贷**：宽松期含经营贷置换，口径失真。
- **财政存款 ≠ 闲置资金**：季末支出释放流动性，是调度节奏。
- **净误差与遗漏 ≠ 纯热钱**：含统计误差，须结合"其他投资"项看。

## 三、可靠性怀疑三问（欧乐鹰 A1）

对任何数**先问三问**：

1. **谁编**：国家统计局直报？地方上报？部委？民间（财新/MNI）？**直报中央的可靠性 > 地方层层上报**。
2. **怎么编**：样本门槛（如工业 2011 起营收 > 2000 万）、推算方法（相关指标推算法）、是否季调。
3. **有无动机**：政治（保增长目标）、技术（服务业难统计）、文化（不愿如实上报）。

**可信度光谱**：直报中央 + 物理量可验（高信）> 部委口径清晰（中信）> 地方上报 + 政治敏感（低信）。

**边界**：怀疑是**方法**不是**结论**。不得滑向"中国数据全假"的虚无主义——书明确反对，2009 年官方数据与工业、水泥、航运相互吻合即为证据。最终须以交叉验证后的数做判断，而非停留在怀疑。

## 四、物理量体检表（官方指标 ↔ 高频代理）

| 官方指标 | 高频代理 | 逻辑与领先性 |
|---|---|---|
| 工业增加值 | 发电量、六大电厂耗煤、高炉/焦炉开工率、粗钢产量 | 工业用电与产出高度同步，难造假 |
| 固定资产投资 / 基建 | 水泥产量、挖掘机销量、沥青开工率、螺纹钢表观消费 | 施工强度先行 2–4 周 |
| 房地产投资 / 销售 | 30 城商品房成交、100 城土地成交、百强房企销售额 | 销售领先投资 2–3 季，土拍领先基金收入 |
| 消费社零 | 乘用车零售、30 城餐饮流水、快递业务量 | 汽车 + 餐饮是波动主源，周频可验 |
| 进出口 | 集装箱吞吐量（SCFI/CCFI）、BDI、韩国前 10 日出口 | 港口与韩国前瞻领先 1–2 周 |
| 物价 CPI | 商务部食用农产品价格指数（R²≈0.9）、农业部批发 200 指数 | 周频食品项前瞻 |
| 物价 PPI | 螺纹钢、原油、铜价、南华工业品指数 | 生产资料价格月内可推 |
| PMI 价格分项 | 出厂价分项 → PPI 环比（R²≈0.81） | 月内前瞻 |

**用法**：官方读数与物理量**背离**时，先看背离能否被口径解释；解释不了则降 verdict，并在解读卡中明示"物理量未印证"。

## 五、时效边界（必读）

- 李奇霖书稿数据截至 **2019–2020 年**（含 2020 疫情与基期轮换）；此后统计改革（研发支出纳入、PMI 样本调整、专项债扩容）已改多处口径。
- 所有占比数值（如增值税 38.6%、土地出让金 84%、四本账结构）为**书稿时点**，使用前以财政部 / 统计局 / 央行最新公布为准。
