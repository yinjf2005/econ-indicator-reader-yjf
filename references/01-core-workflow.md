# 01 · 核心工作流（七步 SOP）

**上游**：`SKILL.md` §四。本文件给出每一步的可执行规程、判定表与回退条件。

---

## 〇、进入判定

| 检查 | 命中则 |
|---|---|
| 请求是预测未来数值 | 拒绝预测 → 改给情景树 + 观测触发条件 |
| 请求是买卖/点位 | 拒绝 → 降级为"若 X 则 Y"条件式情景，标注非投资建议 |
| 请求是计量估计 / 回归 | 转 `econpaper-architect` |
| 请求是"查最新数据" | 转 `finance-wscn-brief`，或给出取数通道（`08-integration.md`） |
| 其余 | 进入七步 |

**口径快检（S0）**：若用户已给出"指标 + 数值 + 时期 + 口径"，走**快通道**；否则进**澄清模式**。

澄清模式补问优先级：口径 > 发布方/时点 > 共识预期 > 上下文。最多问 3 个，问完即出卡，同时在卡中标注"以下按缺省假设 X 处理，可能降级"。

---

## S1 · 指标归位

1. 在 `06-indicator-dictionary.md` 中定位指标；不在字典中 → 标注"超纲"，按通用规程处理并降低 verdict。
2. 记录五要素：`指标名` / `发布方` / `口径` / `频率` / `发布时点`。
3. 判定该指标的**市场敏感度**（高/中/低，见字典"敏感度"列）与**时滞**（领先/一致/滞后，见 `02-read-four-questions.md` §三件套）。
4. 输出：`{指标, 发布方, 口径, 频率, 敏感度, 时滞角色}`。

## S2 · 读数四问（强制闸门）

逐项回答，缺一即触发 **H1**：

| 问 | 判定要点 |
|---|---|
| **基期** | 同比的基期是否含异常（疫情、春节错位、基数效应）？跨基期比较须重估权重 |
| **季调** | 是否季调？未季调的环比在 1–2 月不可用；1–2 月只看累计值 |
| **年化** | 环比折年率还是累计同比？不得混用 |
| **名实** | 名义还是实际？实际值须说明平减指数来源 |

叠加**可靠性怀疑三问**（`07-pitfalls.md` §二）与**物理量体检**（`07-pitfalls.md` §三）。

## S3 · 结构归位（三维矩阵）

在 `03-logic-matrix.md` 中定位：

1. **逻辑方式**（演绎 / 归纳 / 溯因）：该读数用于验证理论、提炼规律、还是解释反常？
2. **逻辑样态**（链 / 树 / 环 / 网 / 螺旋 / 场）：该读数在结构中是环节、分支、反馈、节点、累积阶段还是环境变量？
3. **时滞**（横轴属性）：该读数是领先 / 一致 / 滞后？领先几期？

输出一行式定位，例：`溯因 × 环（政策→地产→信用→财政）× 滞后 2 季`。

## S4 · 双轨解码

四组对照，每组给出方向判断与背离说明：

| 轨 | 判读 |
|---|---|
| 同比 ↔ 环比 | 同比看趋势水平，环比看边际动能；背离即"趋势未变但动能已转" |
| 存量 ↔ 流量 | 存量看水位，流量看速度；用流量解释存量变化 |
| 名义 ↔ 实际 | 名义含价格，实际剔价格；背离即价格因素主导 |
| 领先 ↔ 一致 ↔ 滞后 | 三件套交叉；领先指标转向而一致指标未动 → 拐点临近但未确认 |

## S5 · 语义化与数学闸门

产出 L2 语义 JSON（schema 见 `04-semantic-json.md`），必标字段缺失即 **H2**；过**十项校验**，任一不过则触发降级或回退。

## S6 · 预期层

1. **surprise** = 实际 − 共识；无共识则显式声明（否则 **H4**）。
2. **敏感度五特性**评级（`05-expectation-layer.md` §二）。
3. **多资产交叉验证**：利率 / 汇率 / 商品 / 权益 是否同向印证。
4. **冲突仲裁**：出现指标打架时按 硬 > 软 > 轶事，**拐点处反转**（软指标先行）。

## S7 · 输出与校准

- 默认出**解读卡**（`assets/interpretation_card.md`）。
- 用户要求展开 → 七层报告：结论 / 四问 / 归位 / 双轨 / 信源 / **预期差与决策含义** / 对照与反例 / verdict。
- verdict 四门闸门（A–D）与词表见下表；**必须附"未校准"声明**。

| 闸门 | 判定 |
|---|---|
| A 口径闸门 | 四问答齐且发布方可追溯 |
| B 一致性闸门 | 双轨无未解释背离，或背离已给出机制解释 |
| C 交叉验证闸门 | 至少一个独立信源/物理量印证 |
| D 预期闸门 | surprise 已算或已声明无共识 |

| 四门通过情况 | verdict |
|---|---|
| A–D 全过 | `可支撑` |
| 过 3 门 | `倾向成立（未校准）` |
| 过 2 门 | `证据不足` |
| 过 ≤1 门 | `不可支撑` |

## 硬阻断与回退

| 编号 | 触发条件 | 处置 |
|---|---|---|
| H1 | 四问缺一 | 停止 → 补问或按缺省假设降级标注 |
| H2 | L2 必标字段缺 | 停止 → 补标或标注"语义不完整" |
| H3 | verdict 无依据链 / 伪称校准 | 停止 → 补依据链 + 未校准声明 |
| H4 | 涉及市场反应未算 surprise 且未声明 | 停止 → 补算或显式声明 |
| H5 | 来源不可追溯 | 停止 → 要求补发布方与发布时点 |

机器校验：`python scripts/check.py <file.md> [--json]`；回归：`python scripts/check.py --selftest`。
