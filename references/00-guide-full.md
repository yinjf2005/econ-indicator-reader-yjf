## 一、本指引是什么、给谁用、与谁配合

### 1.1 定位

本指引是一套**把原始经济数据加工成"可论证的经济语义"**&#x7684;标准化流程。它回答三类问题：

1. 这个数字**说的是什么**（口径、量纲、历史位置）；
2. 这个数字**背后发生了什么**（机制、逻辑、政策、结构）；
3. 这个数字**意味着我该做什么**（预期差、决策含义、验证路径）。

核心痛点：看到"CPI 同比 +0.3%"不知道是好事坏事、与自己何干、接下来往哪走。本指引把数据变答案。

### 1.2 不是什么（命中即拒绝，不得强行套流程）

| 命中情形                     | 拒绝/转出                                 |
| ------------------------ | ------------------------------------- |
| "该不该买这只股票"               | 拒绝投资建议 → 转 `a-share-fvt-watch` / 行情接口 |
| 预测具体点位、汇率点位、价格目标         | 拒绝 → 只给方向与情景区间                        |
| 需要因果识别与计量估计（DID/IV/RDD…） | 转 `econpaper-architect` 的 D-2~D-7     |
| 需要把一句经济判断数学化（"多花一块钱值不值"） | 转 `econ-math-mapper`                  |
| 写期刊向经济学论文                | 转 `econpaper-architect`               |
| 做行业/市场/投资研报              | 转 `research-report-standard`          |
| 把政治立场、伦理判断量化             | 拒绝，只做概念性讨论                            |

### 1.3 与两个既有技能的关系（**建议采用"中间层管道 + 钩子式集成"**）

```
econpaper-architect（论文/实证层）
        ▲ 供给：数据审计结论、指标语义、变量口径说明
        │
【经济指标解读参考】←── 本指引
        │ 中间层：原始数据 → 可论证的经济语义
        ▼ 供给：L2 语义 JSON（存量/流量、名义/实际、时间框架、外生/内生）
econ-math-mapper（数学映射层）
```

**三条关系裁定（建议）**：

| 关系                      | 裁定                     | 理由                                                                                                                                       |
| ----------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 与 `econpaper-architect` | **上游增补，不接管内核**         | 对齐 econpaper §12.2「禁止越界」原则：本指引只补 S2 资料盘点、S7 数据节的**数据审计与指标语义**，绝不接管 D-2~D-7 的模型选型裁决。逻辑矩阵（§4.2）直接复用其 `05-guide-logic.md` 的 3×6 定义，保证同一套词表。 |
| 与 `econ-math-mapper`    | **管道前件，输出 L2 语义 JSON** | 本指引把指标解码成结构化语义（含存量/流量、名义/实际、时间框架、外生/内生四组必标字段），正好是 econ-math-mapper 的 L2 输入；其 L4 十项校验反向作为本指引的"数学化闸门"（§八）。二者是**前件—后件**，不是竞争关系。             |
| 与两者共同                   | **独立成技能，钩子式调用，不嵌入**    | 两个既有技能均有"不得改写既有阶段定义/铁律/硬阻断"的约束（econpaper §十兼容性铁律）。独立建技能、在其 SKILL.md 里写"外部 skill 集成"钩子，比嵌入更安全、可独立升级。                                      |

**一句话定位建议**：econpaper 是"怎么写论文"，econ-math-mapper 是"怎么翻译成数学"，本技能是"**怎么读懂那个数**"。三者串起来是：读数 → 语义 → 数学 → 论证。

### 1.4 输入端：六类输入与解码规则

v1.0 为五类，v2.0 增加第六类（预期/共识类）。

| 类型               | 形式                              | 解码规则                                                    |
| ---------------- | ------------------------------- | ------------------------------------------------------- |
| 一、数值型数据          | 单指标或多指标组合                       | 先过 §二 读数四问 → §三 归位 → §四 双轨解码                            |
| 二、指标关系描述         | "M1 增速持续低于 M2""CPI-PPI 剪刀差扩大"   | 先判关系类型（因果/相关/同步）→ 选逻辑样态（§4.2）→ 双轨解码                     |
| 三、概念定义与术语        | "什么是潜在增长率""财政乘数如何理解"            | 概念定位 → 指标映射 → 操作化转换 → 与核心指标网络对接                         |
| 四、政策文本与文件摘要      | "适度加力、提质增效的积极财政政策"              | 定性轨道政策映射（§4.3）+ 政策影响函数（含量纲校验）                           |
| 五、混合输入           | 数据 + 关系 + 概念                    | 串行：概念定义 → 指标归位 → 读数四问 → 数据解码 → 关系推演 → 综合判断              |
| **六、预期与共识类（新增）** | "市场对这次 CPI 的共识是多少""数据出来为什么股债双杀" | 走 §六 预期层：取共识 → 算 surprise = 实际 − 共识 → 多资产交叉验证 → 只对偏离下结论 |

### 1.5 核心原则（六条）

1. **双轨并行，缺一不可。** 定量回答"数字是多少、变了多少、历史上在什么位置"；定性回答"背后发生了什么、为什么、意味着什么"。中村力《魔鬼分析学》：定量防"算错答案"，定性防"问错问题"，缺定性则算得精确但无关，缺定量则说得漂亮但不可信。
2. **先翻译，再分析。** 术语必须先落生活语言，再进入分析。普通大众看不懂的解读是失败的。
3. **先审口径，再读数。** 任何增长读数内含四重口径选择（和谁比、调没调、化没化、名还是实），不问清口径就读数等于没读（鲍莫尔 A4）。
4. **结论必须可验证。** 每个判断标注信源 + 给出"你可以通过什么方式确认它对不对"的验证路径。
5. **区分"数据好不好"与"超没超预期"。** 资产价格对 surprise 定价，不对绝对水平定价（鲍莫尔 A2）。只说"数据好"而不说"好过预期多少"，等于没说。
6. **结论对行动负责。** 分析报告不落到"所以做/不做 X"等于未完成（中村力 A10）。

## 二、第 0 步：读数四问（强制前置闸门）

> 来源：鲍莫尔《经济指标解读》A4。任何读数进入分析前，必须先过这四问。

| 问           | 内容                          | 典型陷阱                                                 |
| ----------- | --------------------------- | ---------------------------------------------------- |
| **Q1 和谁比**  | 环比 / 同比 / 跨周期比？基期是否低基数？     | 低基数同比单独标注，勿与正常同比混排；1–2 月只看累计值（李奇霖误区②）                |
| **Q2 调没调**  | 是否季调？季调回溯 5–10 年识别重复趋势      | 1–2 月零售惯性下滑、7 月汽车换线停产≠基本面恶化；罢工/灾害/疫情等突发冲击季调管不了，须手动标注 |
| **Q3 化没化**  | 月×12、两月×6、季×4；年化是"速度"不是"总量" | 月度 0.1% 抖动年化后放大成 1.2%（二手转引·《经济学人指标指南》，须核验）           |
| **Q4 名还是实** | 名义含通胀，实际才对应物量与福利            | 工资 +5% 对通胀 4% = 实涨 1%；销售额 +10% 全靠提价 = 实际零增长          |

**衰退判定纠偏**：媒体常用"连续两季度负增长"定义衰退——这只是粗糙风向标。NBER 综合就业增长、个人收入、工业产值、GDP 多指标判定（鲍莫尔 A4 转述：1854 年以来收缩平均约 17 个月，二战后约 10 个月；**该统计为书中时点数据，其后新增周期未覆盖，引用须核验**）。

**操作要求**：四问答案（基期/季调/年化/名实）必须写进分析笔记的元数据，供复盘与复用。四问未过，读数不得进入结论。

## 三、第一步：指标归位（四维）

### 3.1 维度一：时间——先行 / 同步 / 滞后

| 类型 | 含义        | 典型指标                                | 解读重心        |
| -- | --------- | ----------------------------------- | ----------- |
| 先行 | 比经济周期更早转折 | PMI、社融增速、M1 增速、新开工项目数、建造许可、首申、收益率曲线 | **预示了什么**   |
| 同步 | 与经济周期同步变化 | GDP 增速、工业增加值、社零总额、就业                | **现在怎么样**   |
| 滞后 | 比经济周期更晚转折 | 失业率、CPI（部分情形）、企业利润、单位劳动成本           | **此前判断对不对** |

大白话：先行指标是"天气预报"（看到乌云知道要下雨），同步指标是"正在下的雨"，滞后指标是"雨后的积水"。

### 3.2 维度二：领域——生产 / 需求 / 物价 / 金融 / 财政

| 领域 | 指标                      | 回答什么      |
| -- | ----------------------- | --------- |
| 生产 | GDP、工业增加值、服务业生产指数       | 经济产出了多少   |
| 需求 | 固定资产投资、社零总额、进出口         | 产出被怎么用了   |
| 物价 | CPI、PPI、GDP 平减指数        | 价格发生了什么变化 |
| 金融 | 社融、M1/M2、信贷、PMI         | 资金在怎么流动   |
| 财政 | 一般公共预算收支、政府性基金、专项债、实际赤字 | 政府这只手在怎么动 |

四领域不孤立：GDP 经生产法拆出工业增加值，经支出法拆出投资/消费/净出口，物价与金融既是结果也是先行信号。归位时须同时标注上下游关系。

### 3.3 维度三：统计口径——数据的"出身"

**常见口径陷阱**（李奇霖 C2 + 欧乐鹰）：

- 固定资产投资完成额 ≠ 固定资本形成总额（前者含土地购置费与旧设备，500 万门槛；后者不含商品房销售增值，2017–18 因研发支出纳入而背离）；
- 社零总额 ≠ 居民消费支出（前者仅商品零售+餐饮，不含教育/医疗/住房等服务消费）；
- 官方 PMI ≠ 财新 PMI（官方 3000+ 家、偏中上游大型国企；财新 400–650 家、偏中小出口民企，调查时点更早）；
- 服务业生产指数 ≠ 三产 GDP 同比（仅覆盖市场性活动，短期领先约半年，宜方向参考）；
- 海关差额 ≠ GDP 净出口（漏服务贸易、到岸/离岸价差）；
- 外汇占款 ≠ 外汇储备（历史成本 vs 市值口径）；
- 社融 ≠ M2（统计范围有缺口，看二者增速差的信息）；
- 狭义赤字 ≠ 实际赤字（漏政府性基金调入与结转结余）。

**十大使用误区硬清单**（李奇霖 C2，引数据前必查）：

| # | 误区                     | 对策                       |
| - | ---------------------- | ------------------------ |
| ① | 美元/人民币计价混用（可致增速差约 9pp） | 先声明币种，跨年汇率大变优先美元计价       |
| ② | 春节错位外推（1 月冲高/2 月跳水判趋势） | 1–2 月只看累计值，其余看季调环比       |
| ③ | 海关差额 = GDP 净出口         | 用外管局国际货物服务贸易数据近似         |
| ④ | CPI 旧基期权重套新数据          | 跨基期重估权重，用"拉动点数÷分项同比"反推   |
| ⑤ | 翘尾当新涨价                 | 拆翘尾（年初可测）+ 新涨价，只看新增部分    |
| ⑥ | 社融 = M2                | 看社融 − M2 增速差             |
| ⑦ | M1−M2 单月判趋势            | 1–2 月春节错位失真，看 1–2 月平均或季调 |
| ⑧ | PMI 绝对值迷思（"过 50 就行"）   | 看动能变化与分项链，中国制造业长期 >50    |
| ⑨ | 外汇占款 = 外汇储备            | 分开看：前者看基础货币，后者看家底        |
| ⑩ | 狭义赤字 = 实际赤字            | 用含调入的实际赤字评积极财政力度         |

> **时效边界**：李奇霖全书数据截至 2019–2020 年；此后统计改革（研发投入纳入、PMI 样本调整、专项债扩容、M1 口径 2025 年 1 月修订）已改多处口径。**所有书稿时点的占比数值使用前须以最新官方公布为准。**

### 3.4 维度四（新增）：敏感度五特性——先盯谁

> 来源：鲍莫尔 A3。监控清单是**周期的函数**，不是常量。

| 特性   | 判据                                      |
| ---- | --------------------------------------- |
| 精确性  | 修订是否频繁（老被修改的指标，市场重要性不显著）                |
| 时效性  | 发布滞后长短（滞后两个月的信贷数据再准也没人交易）               |
| 周期阶段 | 当前是否踩中它的"主场"（衰退期看量：新屋开工、汽车销售；过热期看价：CPI） |
| 预测能力 | 历史上能否领先见拐点（如耐用品预订量）                     |
| 关注度  | 资金关注度高低（资产风险越大，盯的指标越特别）                 |

**市场敏感度 Top（鲍莫尔表 1-1~1-3 转述，为第 2 版时点快照，排序会漂移，仅作校准参照）**：

| 排名 | 股票最敏感     | 债券最敏感     | 美元最敏感 |
| -- | --------- | --------- | ----- |
| 1  | 就业报告      | 就业报告      | 就业报告  |
| 2  | ISM 制造业调查 | CPI       | 国际贸易  |
| 3  | 周度首申      | ISM 制造业调查 | GDP   |
| 4  | CPI       | PPI       | 经常项目  |
| 5  | PPI       | 周度首申      | 工业产值  |

**操作外壳**：五特性各 1–5 分 → 按当前周期阶段加权 → 每季度或周期转折信号出现时复评切换仪表盘。**打分法为操作化外壳，权重无实证校准，须使用者自校。**

### 3.5 维度五（新增）：可靠性怀疑三问 + 修订阶梯

> 来源：欧乐鹰 A1/A2/A6 + 鲍莫尔 A5。

**怀疑三问**（怀疑是方法不是结论，最终仍需以交叉验证后的数做判断）：

1. **谁编**：统计局直报？地方上报？部委？民间？→ 直报中央 > 部委口径清晰 > 地方层层上报
2. **怎么编**：样本门槛（如工业营收门槛）、推算方法、是否季调
3. **有无动机**：政治目标、技术困难（服务业难统）、文化因素（不愿如实上报）

**体检工具**：用难造假的物理量交叉验证——发电量、客货运输量、港口吞吐、粗钢/水泥产量。  
**反虚无主义**：怀疑≠否定。欧乐鹰明确指出，2009 年官方数据与工业/水泥/航运数据吻合即为其可靠性证据。

**修订阶梯与初值纪律**：

- 数据存在"初值 → 修正值 → 终值"阶梯，中国宏观数据修订幅度不可忽略；
- **初值不得单独承载结论**，须标注"基于初值，待修订"；
- 修订幅度超过历史均值 2 倍标准差 → 触发"数据可靠性预警"（见 §5.5 规则二）。

## 四、第二步：双轨解码

### 4.1 定量轨道：回答"数字说了什么"

| 步骤 | 动作       | 要点                                      |
| -- | -------- | --------------------------------------- |
| 1  | 四问审计     | 见 §二，前置                                 |
| 2  | 计算变动率    | 同比（消季节、看趋势）、环比（看动能）、累计同比；二者背离须警惕        |
| 3  | 定位历史分位   | 至少回溯 3 年（重要判断回溯 5–10 年），标注均值/中位数/极值/百分位 |
| 4  | 构建关联指标矩阵 | 按家庭/企业/政府/金融/海外五个部门分别列核心指标，不孤立看一个数      |
| 5  | 贡献度分解    | 拉动点数 = 分项增速 × 分项权重；结构型指标先分解再算贡献         |
| 6  | 引入定量模型   | 按需选用（下表），并过 §八 数学化闸门                    |

**常用定量工具速查**：

| 工具          | 适用场景          | 操作要点                           |
| ----------- | ------------- | ------------------------------ |
| 同比/环比拆解     | 任何指标初步分析      | 同比看趋势，环比看动能，背离须警惕              |
| 历史分位定位      | 判断所处水平        | 至少回溯 3 年，标注均值/中位数/极值           |
| 贡献度分解       | GDP、CPI 等综合指标 | 拆解各分项拉动点数                      |
| 相关性矩阵       | 多指标联动         | 滚动相关系数识别传导关系；**相关≠因果**         |
| 简单回归预测      | PMI 预测 GDP 等  | 弹性系数须用本国数据校准，不得照搬他国            |
| 滤波分析（HP 滤波） | 区分趋势与周期       | 分离潜在 GDP 与实际 GDP，算产出缺口；注意端点不稳定 |
| 时差相关分析      | 确定领先期         | 用于确定"领先几个月"，逻辑序的量化工具           |

大白话示例：社零同比 +3% 但环比 −0.5%，且消费者信心连续 3 个月下滑 → 消费增速放缓、短期动能不足、预期在恶化。

### 4.2 定性轨道框架一：逻辑推演（**v1.0 六结构 → v2.0 三维矩阵**）

> 依据：`econpaper-architect` `references/05-guide-logic.md` §4.1–§4.5。

**⚠️ 版本裁定说明（重要）**：v1.0 列了"链/树/环/网/场/**序**"六种。与 econpaper 底座对照后存在冲突——econpaper 的六种样态为"链/树/环/网/**螺旋**/场"，无"序"。裁定如下：

- **"逻辑序"不是样态，而是横轴属性**。任何样态的每个节点都要标注时滞参数（PMI 领先 GDP 3–12 个月、M1 领先 PPI 1–3 个季度），时滞是"贴在边上"的属性，不是第六种结构。多周期嵌套（基钦周期嵌在朱格拉周期中）归入螺旋的时间递归性。
- **补入"逻辑螺旋"**（A→B→C→A'→B'→C'…递归上升）。典型场景：政策发力 → 数据改善 → 政策退坡 → 数据回落 → 政策再加码。这是中国经济分析中极常见的"政策—数据"迭代结构，v1.0 完全缺失。
- **补入"逻辑方式"维度**（演绎/归纳/溯因）——v1.0 只有样态没有方式，导致"同一个逻辑链"不知该从假设出发还是从数据出发。

**因此 v2.0 采用三维：逻辑方式（3）× 逻辑样态（6）× 时滞标注（每个节点）**。

#### 三种逻辑方式

| 方式     | 起点                          | 适用                             |
| ------ | --------------------------- | ------------------------------ |
| **演绎** | 假设 → 模型 → 求解 → 比较静态         | 有理论框架可依（如"根据菲利普斯曲线，失业下降应推升通胀"） |
| **归纳** | 数据 → 模式 → 统计推断 → 结论         | 数据驱动、理论不明的探索性解读（多数指标解读的默认方式）   |
| **溯因** | 现象 → 候选机制 → 排除竞争解释 → 保留最佳解释 | 反常数据归因（"为什么社融超预期但工业增加值走弱"）     |

#### 六种逻辑样态

| 样态         | 结构   | 典型数学工具   | 经济分析示例                     | 操作要点                 |
| ---------- | ---- | -------- | -------------------------- | -------------------- |
| 链          | 线性序列 | 代数、递推    | PPI → CPI 传导               | 标注每节点传导时滞与传导效率       |
| 树          | 层级分支 | 图论、递归    | GDP → 三次产业 → 细分行业          | 算各分项贡献点数             |
| 环          | 单一回路 | 动力系统、不动点 | 房价↑→财富效应→消费↑→GDP↑→房价↑（正反馈） | 判正/负反馈，评估回路周期        |
| 网          | 多重连接 | 图论、网络科学  | 社融-M1-工业增加值-物价 网络          | 识别核心节点与瓶颈节点          |
| **螺旋（新增）** | 递归上升 | 迭代、层次建模  | 政策加码→数据改善→政策退坡→数据回落→再加码    | 标注循环层次与每圈增量；无增量则退化为环 |
| 场          | 连续分布 | 场论、微分方程  | 消费者信心弥散、系统性风险传染            | 关注"场强度"与"场边界"        |

**样态嵌套关系**（econpaper §4.6）：链 ⊂ 树 ⊂ 网 ⊂ 场，环 ⊂ 网 ⊂ 场，螺旋 ⊂ 网 ⊂ 场。标注的是"**主导样态**"，非唯一析取。

#### 逻辑方式 × 主导样态 → 自动生成的解读顺序（节选，完整表见 `05-guide-logic.md` §4.5.2）

| 组合     | 自动生成的解读链                                      |
| ------ | --------------------------------------------- |
| 归纳 + 链 | 数据 → 模式 → 统计推断 → 因果结论 → 异质性分支 → 多路径交叉验证 → 稳健性 |
| 归纳 + 树 | 数据 → 异质性划分 → 子样本效应 → 分支比较 → 总体结论              |
| 归纳 + 环 | 数据 → 动态关系 → 反馈识别 → 脉冲响应 → 结构性解释               |
| 演绎 + 链 | 假设 → 模型 → 求解 → 比较静态 → 结论                      |
| 溯因 + 链 | 现象 → 候选机制 → 排除竞争解释 → 保留最佳解释                   |
| 溯因 + 环 | 现象 → 反馈机制 → 涌现 → 参数扫描 → 稳健性                   |

**落到输出的要求**：不得只给标签（"我用归纳+链"），必须把组合翻译成具体的解读叙事顺序写进正文。

### 4.3 定性轨道框架二：PEST-GES/GEP 扫描（保留 v1.0，精简）

| 维度           | 扫描问题           | 典型指标               |
| ------------ | -------------- | ------------------ |
| P 政治         | 政策方向是宽松还是收紧？   | 财政赤字率、政策利率、专项债额度   |
| E 经济         | 周期处于什么位置？      | GDP 增速、产出缺口、PMI    |
| S 社会         | 就业和收入状况如何？     | 失业率、居民可支配收入增速      |
| T 技术         | 产业技术变革方向？      | 研发投入强度、数字经济占比      |
| GES 绿色-环境-社会 | 环境与社会综合影响      | 单位 GDP 碳排放、ESG 披露率 |
| GEP 生态系统生产总值 | 自然资本变化如何影响可持续性 | 生态系统服务价值、生态补偿金额    |


GES 在宏观解读中作为"社会"维度的深化扩展：E 看碳排放/能耗/污染是否随指标同步变动，S 看就业/分配/公平影响，G 看政策透明度与制度环境。GEP 作为资源型产业、生态补偿、绿色金融类指标的辅助维度。

### 4.4 定性轨道框架三：政策映射（**含量纲修正**）

#### 政策影响函数（v2.0 修正版）

v1.0 原式：`Δ目标变量 = 政策强度 × 传导系数 × 时滞因子`  
**问题**：时滞因子量纲不明——若以"月"为单位，则等式右侧带时间量纲、左侧不带，量纲不一致（违反 econ-math-mapper 硬规则 6）。

**v2.0 修正**：

$\Delta Y = S \times k \times \lambda(\tau)$

| 符号              | 含义                                                                | 量纲            |
| --------------- | ----------------------------------------------------------------- | ------------- |
| $S$             | 政策强度（政策工具变动幅度，如新增专项债 5000 亿元）                                     | 与目标变量同量纲的投入单位 |
| $k$             | 传导系数（边际影响，如财政乘数 1.2–1.5）                                          | 无量纲           |
| $\lambda(\tau)$ | **兑现率**：时滞 $\tau$（月/季）对应的兑现比例，$\lambda \in [0,1]$，随 $\tau$ 递增趋近 1 | 无量纲           |
| $\Delta Y$      | 目标变量变动量                                                           | 与 $S$ 同量纲     |

**操作流程**：识别政策方向 → 估算政策强度 $S$ → 查找/估算传导系数 $k$（须注来源，无来源则标 `UNVERIFIED`）→ 标注时滞 $\tau$ 与兑现率 $\lambda$ → 输出预期影响量。

**示例**：新增专项债额度 4.4 万亿元（较上年 +5000 亿元）。  
$\Delta$基建投资 ≈ 5000 亿 × $k$(0.6–0.8) × $\lambda$(τ=2–3 季度，取 0.7) ≈ 2100–2800 亿元。  
**所有系数均为占位值，须以本国数据校准，输出时须标注 `UNVERIFIED`。**

#### 政策效益函数

$\text{净效益} = \Delta(\text{目标达成}) - C_{\text{财政}} - C_{\text{机会}}$

成本须含机会成本（如投资性支出挤占公共服务）。判断"值不值"时，效益与成本须同量纲（通常统一为福利或 GDP 当量），否则不得相减。

### 4.5 定性轨道框架四：数据分类 × 差异化判断（保留 v1.0 SWOT 设计）

| 类型  | 特征                    | 核心判断问题     | SWOT 应用             | 辅助工具               |
| --- | --------------------- | ---------- | ------------------- | ------------------ |
| 总量型 | 数值大、变化慢、基数效应大         | 趋势是加速还是减速？ | S/W 看水平，O/T 看趋势     | 3 个月移动平均、累计同比、历史分位 |
| 比率型 | 有合意区间，过高过低都有问题        | 偏离合意区间多远？  | S/W 看偏离方向，O/T 看回归动力 | 阈值分析、均值回归          |
| 扩散型 | 以 50/100 为荣枯线，看方向不看幅度 | 在荣枯线哪一侧？   | S/W 看分项结构，O/T 看方向   | 荣枯线、分项拆解           |
| 结构型 | 关注组成比例                | 结构在升级还是降级？ | S/W 看占比变化，O/T 看升级趋势 | 贡献度分解              |
| 预期型 | 主观判断、自我实现、波动大         | 预期与行为是否一致？ | S/W 看预期水平，O/T 看背离   | 舆情交叉验证、行为一致性检验     |

**预期型指标特别提示**：人们说的和做的可能非常不同，政治因素也可能影响调查结果（鲍莫尔 A7）。软指标只能作**证词**，不能作**判决**——"不能仅凭对家庭心理状态的观察来判断消费支出的前景"。

### 4.6 双轨合流：定量与定性必须"对话"

| 情形   | 处理                                            |
| ---- | --------------------------------------------- |
| 一致   | 定量显示改善 + 定性判断基本面确实好转 → 结论较可靠                  |
| 背离   | 定量改善但定性发现改善来自基数效应/短期扰动 → **下调置信度**，并解释张力来源    |
| 主次切换 | 数据质量高、逻辑清晰 → 以定量为主；数据有口径问题或外部冲击大 → 以定性为主（中村力） |

**操作要求**：最终输出必须同时呈现定量与定性结论，明确标注"一致 / 存在张力"，张力须解释来源。

### 5.3（新增）冲突仲裁规则

> 来源：鲍莫尔 A7。多指标打架是常态而非异常——冲突本身携带结构信息。

**仲裁三步**：

1. **查口径与时间差**：它们看的是不是同一个角落？（不同月份？不同样本？季调与否？名实是否一致？）
2. **按基准权重定序**：**硬数据（事后统计）> 软数据（调查与预期）> 轶事（定性描述）**
3. **拐点处反转权重**：硬数据是后视镜；当怀疑处于拐点时，轶事与定性证据往往先行（实例：2007 年 10 月 FOMC 会议记录显示多位委员依赖本区"轶事"预警住房市场溢出风险，联储已于当年 9 月启动降息，而同期硬数据尚未显示衰退）。**反转时必须在输出中显式说明"因怀疑拐点，已反转仲裁次序"。**

**反直觉行动条款**：消费者信心高不必然对应消费支出强（中间隔着收入、信贷等中介）。心理类软指标只作证词。

### 5.4 可靠性评估维度

| 维度      | 高可靠        | 低可靠       |
| ------- | ---------- | --------- |
| 统计方法透明度 | 公开方法论和样本设计 | 方法不透明     |
| 样本代表性   | 覆盖面广、抽样科学  | 样本量小或偏向性强 |
| 历史修订幅度  | 初值与终值差异小   | 频繁大幅修订    |
| 独立性     | 独立于政策目标    | 受政策目标影响大  |

### 5.5 接口规则（v1.0 保留 + v2.0 增强）

**规则一·优先级**：默认第一层；缺失或需交叉验证时调第三层；跨国对比调第四层；第二层需确认权限。

**规则二·交叉验证触发**：

- 单一指标来自单一信源 → 自动触发交叉验证请求；
- 官方数据与替代数据方向背离 → 强制输出"数据分歧提示"；
- 数据修订幅度超历史均值 2 倍标准差 → 标注"数据可靠性预警"；
- **（新增）**&#x8F6F;指标与硬指标方向背离 → 按 §5.3 仲裁，不得默认硬数据正确。

**规则三·标注格式**：`[信源名称] [发布日期] [指标名称] [数值] [单位] [口径四问答案]`  
示例：`[国家统计局] [2025-05-31] [制造业PMI] [49.5] [点] [同比/季调/未年化/名义]`

**规则四·更新监测**：月度指标发布后 24h 内更新；季度 48h；年度 7 天。

## 六、第三步·并行：预期层——市场已定价了什么（**v2.0 新增整章**）

> 来源：鲍莫尔 A1/A2/A8。v1.0 的最大缺口：全篇未处理"市场已定价了什么"。

### 6.1 发布纪律（Lockup）

关键数据发布有信息公平机制（Lockup）：数据发布前对市场参与者同步可得，不得提前泄露、不得选择性披露。**操作含义**：解读"数据发布瞬间"的市场反应，必须先确认发布时点与信息可得性，否则会误判为"市场提前知道"。

### 6.2 预期差定价（核心）

$\text{surprise} = \text{实际值} - \text{共识预期}$

| 步骤 | 动作                                                          |
| -- | ----------------------------------------------------------- |
| 1  | **发布前取共识**：来自对经济学家的抽样调查（Bloomberg/道琼斯/路透/国际市场新闻社等）；共识是会漂移的锚 |
| 2  | **记录发布前价格与仓位**：把"已定价部分"与潜在新信息切开                             |
| 3  | **发布瞬间算偏离**：方向与相对幅度（偏离/共识的百分比通常比绝对差更有意义）                    |
| 4  | **只对偏离反应**：符合预期 → 不动；远超/远逊 → 顺 surprise 方向行动                |
| 5  | **多资产交叉验证**：同一 surprise 在债、股、汇上的指向应自洽；矛盾则降低仓位置信度            |
| 6  | **复盘 surprise 序列**：跟踪同一指标连续数月的 surprise 方向，识别系统性高估/低估       |

**这一条同时解释了"利好出尽"与"利空不跌"**：好数据若已被充分预期，surprise 为零，行情自然乏善可陈；"坏数据反而上涨"往往意味着坏得没有预期中那么坏。

### 6.3 多资产传导（就业报告为例）

| 资产 | 强就业的传导                         |
| -- | ------------------------------ |
| 债券 | 通胀担忧升温 → 债价跌、收益率升              |
| 股票 | 收入与消费预期改善 → 涨（但若已过热、引发紧缩预期则除外） |
| 美元 | 吸引外资流入 → 升值                    |

### 6.4 衰退预警交叉项（鲍莫尔 A8）

收益率曲线倒挂、周度首申、综合领先指标（LEI/OECD CLI）作为衰退预警的交叉验证项。**曲线倒挂是概率性警示而非确定性预言**，须与硬数据、软数据并列观察。

### 6.5 边界

- 无共识可查的小众指标 → 没有锚，就没有"偏离"可言，本层不适用；
- 预测分布极端分裂 → 中值失去代表性；
- 长周期配置（季度以上） → 对月度 surprise 不敏感，本层属战术工具；
- 数据本身质量差、频繁大幅修订 → surprise 是噪音而非信号。

## 七、第四步：与现实对照（五途径）

| 途径          | 操作                   | 判读                                  |
| ----------- | -------------------- | ----------------------------------- |
| 一·可观察现实现象   | 列出 2–3 个可观察证据        | 支持则提置信度，矛盾则修正结论                     |
| 二·大众评论与舆情   | 采集社交平台相关讨论的情绪方向与关注焦点 | 一致则增强，背离则分析原因                       |
| 三·宏观-微观"温差" | 温差 = 宏观指标方向 − 微观体感方向 | 温差来源常在新旧动能转换期的结构性分化；须标注并解释其对预期管理的影响 |
| 四·跨市场情绪     | 资产价格与实体经济感受对照        | 识别"股市涨、体感差"的背离（如财富集中于少数家庭）          |
| 五·国际对照      | 与同类国际指标 / 国际机构评估对照   | 判断走势是否与全球一致（OECD CLI 可用于预测转折点）      |

**舆情比照示例**（v1.0 保留）：公积金派息率 6.30% → 6.15%，仅差 0.15%，网民情绪落差显著——微小差异暴露人们对"损失"的敏感远高于对"获得"的满足。这类信号不直接反映基本面，但反映**预期管理情状**，是重要定性依据。

**媒体叙事纠偏**：区分"基于事实的分析"与"情绪驱动的放大"；媒体叙事与专业判断严重背离时，标注"叙事偏差风险"。

**操作模板**：

```
分析判断：……
对照证据1（现实现象）：…… → 支持/不支持/待观察
对照证据2（舆情信号）：…… → 一致/背离
对照证据3（温差信号）：…… → 温差方向与幅度
综合评估：置信度 + verdict + 理由
```

## 九、第六步：置信度校准与 verdict（`econpaper-architect` §十 接口）

### 9.1 verdict 词表（冻结，不得自创）

| verdict                     | 含义                 |
| --------------------------- | ------------------ |
| `ADOPTED` 采纳                | 证据充分，可直接进结论        |
| `ADOPTED_WITH_CAVEAT` 采纳但存疑 | 可进结论，但须附保留条件       |
| `FLAG_FOR_HUMAN` 转人工        | 证据落在不确定带，须用户拍板     |
| `SPECULATIVE` 推测性建议         | 独立分区呈现，不进已采纳结论     |
| `UNVERIFIED` 未验证            | 未查证处显式声明，不得"沉默即通过" |

### 9.2 四门闸门

| 门                      | 内容                 | 判定                                                               |
| ---------------------- | ------------------ | ---------------------------------------------------------------- |
| **Gate A** 承重信息采信      | 用户对关键数据/制度事实的置信度   | < 0.95 → 禁止在其上展开下游推断，须补证或标"需用户核实"                                |
| **Gate B** 推荐证据强度      | 模型/判断的证据强度         | < 0.30 → 降级为推测性建议，不进已采纳结论                                        |
| **Gate C** 结论敏感性       | 换一种方法/识别策略，结论是否翻供？ | 两路径概率差 > 0.30 → 高敏感；前置检查：任一概率落在 [0.30,0.70] 不得标"稳健"              |
| **Gate D** 决策链稳定性（留一法） | 移除任一环节后整体是否仍成立     | 分散度 ≥0.70 且 确定性 ≥0.50 且未触发硬规则 → 稳定；μ∈[0.30,0.70] 或 σ>0.25 → 高不确定 |

### 9.3 阈值诚实声明（强制）

> **所有阈值（0.95/0.70/0.30/0.25…）均为默认值，无实证校准。** 借用 RLCD/Jev 的**哲学**（校准、结构化决策、显式不确定性），非其已验证性能。中文场景下概率校准存在退化，0.90 的置信度不等于 90% 正确。**输出含置信度数值时，必须在头部标注"LLM 模拟校准（未校准）"。**

### 9.4 路由规则

| 置信度       | 动作        |
| --------- | --------- |
| ≥ 0.85    | 快速复核后进结论  |
| 0.60–0.85 | 完整复核后进结论  |
| < 0.60    | 触发澄清，不进结论 |

## 十、第七步：生成输出（七层结构）

| 层 | 内容               | 示例                                                         |

| 1 | 一句话结论            | "5 月制造业景气度仍偏弱，且中小出口企业比大型国企更困难。"                            |

### 10.1 大白话规范

每次术语后紧跟"术语（大白话：……）"。示例：

- PMI（大白话：问企业老板"这个月生意比上个月好还是差"，50 是分界线）
- 社融（大白话：整个社会从金融系统借到了多少钱，含企业贷款、个人房贷、政府发债）
- M1（大白话：企业和个人手头随时能花的钱；M1 增速低说明大家不敢花、更愿存定期）
- 产出缺口（大白话：实际产出与"满负荷能产出"之间的差；缺口为负说明机器和人都闲着）
- surprise（大白话：数据比大家猜的好多少或差多少——市场只对"猜错的那部分"有反应）

### 10.2 可视化与公式规范

- 走势图（标注关键转折点）、对比柱状图（官方 vs 财新）、逻辑传导示意图（必须双重标注"示意"：图注 + provenance）、关键公式；
- **公式出口**：Word 交付走 pandoc → 原生 OMML 可编辑方程（技能内 `scripts/vizmath/tex2omml.py`），**禁止**把公式渲染成图片贴进 docx；
- **图表出口**：数据图表走 scientific-visualization（技能内 `scripts/vizmath/render_figure.py`，依赖已内联于 `_vendor/`），色盲安全、PDF+PNG 双导出、字体告警须为 0；图内数学标注用 mathtext；
- 量纲/数量级校验结论应写进图注或 provenance，做到"图可自证"。
