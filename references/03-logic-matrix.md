# 03 · 三维逻辑矩阵（指标的结构归位）

**来源**：逻辑方式与逻辑样态定义**复制精简自** `econpaper-architect` `references/05-guide-logic.md` §4.1–§4.6（保持同一词表，避免两个技能打架）。第三维"时滞"为本技能新增。

**与 econpaper 的差异（已获用户裁定）**：原《经济指标解读操作指引 v1.0》的"六种逻辑结构"为 链/树/环/网/场/**序**，与 econpaper 的 链/树/环/网/**螺旋**/场 冲突。裁定：**"逻辑序"降为横轴时滞属性**（每个节点都标时滞，它不是第六种结构），并**补入"逻辑螺旋"**。另补 v1.0 完全缺失的"逻辑方式"维度 → 三维矩阵。

---

## 一、维度一：逻辑方式（3 种）

| 方式 | 定义 | 指标解读中的典型问法 |
|---|---|---|
| **演绎**（Deductive） | 从一般理论推出具体预期，再用数据验证 | "按菲利普斯曲线，失业率降应推升通胀，这次 CPI 是否符合？" |
| **归纳**（Inductive） | 从数据中提炼规律，再上升到结论 | "近六个月社融与新开工同向，能否推出信用→投资的规律？" |
| **溯因**（Abductive） | 面对反常现象，提出候选机制并排除竞争解释 | "PMI 回到 50 上方但发电量没起，最可能的原因是？" |

指标解读中**溯因出现频率最高**（多数提问是"这个反常怎么解释"），演绎次之，归纳最少（需要多样本）。

## 二、维度二：逻辑样态（6 种）

| 样态 | 结构特征 | 时间性 | 分支 | 反馈 | 数学工具 | 指标解读中的例子 |
|---|---|---|---|---|---|---|
| **链** | 线性序列 | 顺序 | 无 | 无 | 代数、递推 | 政策利率↑→房贷利率↑→地产销售↓ |
| **树** | 层级分支 | 顺序/并行 | 有 | 无 | 图论、递归 | 社融→（居民中长贷 / 企业中长贷 / 票据）→ 不同去向 |
| **环** | 单一回路 | 循环 | 无 | 有 | 动力系统、不动点 | 地产销售↓→回款↓→拿地↓→投资↓→就业↓→销售↓ |
| **网** | 多重连接 | 并行 | 多分支 | 多回路 | 图论、网络科学 | 全球供应链：韩国出口、集装箱吞吐、我国进出口互证 |
| **螺旋** | 递归上升 | 层级递归 | 层次性 | 有（上升） | 迭代、层次建模 | 政策加码→数据改善→政策退坡→数据回落→再加码 |
| **场** | 连续分布 | 同时 | 无分支 | 分布式 | 场论、微分方程 | 人口/密度梯度对房价与租金的连续影响 |

**嵌套关系**：链 ⊂ 树 ⊂ 网 ⊂ 场；螺旋是"带层级的环"。判定时**取最小充分样态**，不要一律升级成"网"。

## 三、维度三：时滞（横轴属性）

每个节点都标时滞，**它不是第六种样态**。三值：

| 值 | 含义 | 中国典型 |
|---|---|---|
| **领先** | 先于实体经济转向 | PMI、社融、挖掘机/水泥、30 城地产成交、韩国前 10 日出口 |
| **一致** | 与当前状态同步 | 工业增加值、发电量、货运量、社零 |
| **滞后** | 趋势成立后才有反应 | 工业企业利润、库存周期、财政收支 |

**纪律**：领先指标单独出现不得下定论；至少"一领先 + 一一致"同向才升级 verdict。

## 四、自动逻辑链生成（方式 × 样态）

复制自 econpaper §4.5.2，取指标解读常用组合：

| 组合 | 主结构 | 可扩展为 | 生成链 |
|---|---|---|---|
| 归纳 + 链 | 线性 | 树 / 网 | 数据→模式→统计推断→因果结论→（异质性分支）→（多路径交叉验证）→稳健性 |
| 归纳 + 树 | 分支 | 网 / 场 | 数据→异质性划分→子样本效应→分支比较→（多分支交叉）→总体结论 |
| 归纳 + 环 | 反馈 | 网 / 场 | 数据→动态关系→反馈识别→脉冲响应→（多变量交互）→结构性解释 |
| 演绎 + 链 | 线性 | 螺旋 | 假设→模型→求解→比较静态→（参数迭代修正）→结论 |
| 演绎 + 环 | 反馈 | 螺旋 / 场 | 假设→动态模型→稳态与转移动态→（递归修正）→脉冲响应 |
| 溯因 + 链 | 线性 | 网 | 现象→候选机制→排除竞争解释→（多机制交叉）→保留最佳解释 |
| 溯因 + 树 | 分支 | 网 / 螺旋 | 现象→多机制并存→机制区分→（迭代修正）→条件性机制结论 |
| 溯因 + 环 | 反馈 | 网 / 螺旋 / 场 | 现象→反馈机制→涌现→（校准-模拟-验证循环）→参数扫描→稳健性 |

## 五、归位输出格式

一行式：`{逻辑方式} × {逻辑样态}（{关键路径}）× {时滞角色}`

示例：

- `溯因 × 环（政策→地产→信用→财政）× 滞后 2 季`
- `演绎 × 链（政策利率→房贷利率→地产销售）× 领先 1 季`
- `归纳 × 树（社融→居民/企业/票据）× 一致`

## 六、常见误判

| 误判 | 纠正 |
|---|---|
| 把所有关系都写成"网" | 取最小充分样态 |
| 用"螺旋"描述一次性政策脉冲 | 螺旋要求**递归上升**，单次冲击是链 |
| 把"序"（先后顺序）当第六种样态 | 时滞是横轴属性，标在每个节点上 |
| 忽略方式维度，只判样态 | 方式决定"拿数据干什么"，样态决定"数据在哪" |
