# 05 · 预期层（市场已定价了什么）

**来源**：鲍莫尔 `books/expectation_baumohl/A2_预期差定价法.md`、`A3_敏感度五特性评级法.md`、`A7_指标拼接与冲突仲裁法.md`、`A8_收益曲线倒挂警示.md`。原文见对应文件。

**这是本技能区别于一般数据分析的核心**：同一个数，市场已定价与否，结论可以完全相反。

---

## 一、预期差定价（surprise）

**核心式**：`surprise = 实际值 − 共识预期`（方向与相对幅度并重）。

| 环节 | 规程 |
|---|---|
| 共识来源 | Bloomberg / 道琼斯 / 路透 / 国际市场新闻社等对经济学家的抽样平均 |
| 计算 | 实际 − 共识；同时记录**共识的离散度**（分歧大时 surprise 的定价力下降） |
| 传导（就业报告为例） | 债：数据强 → 价跌息升；股：数据强 → 涨（过热期除外）；美元：数据强 → 升 |
| 口诀 | **先看共识，再看实际，只对偏离反应** |

**纪律**

1. 拿不到共识 → **必须显式声明"无共识锚，无法算 surprise"**（否则触发 H4），并降级 verdict。
2. 预测极端分裂、无共识锚、长周期决策 → 不适用本方法。
3. **利好出尽**与**坏数据反而上涨**都由 surprise 一次性解释：价格反应的是偏离，不是水平。
4. 迁移用法：预期管理 = 先设共识再造正 surprise；预期打满 = 惊喜已被花光。

## 二、敏感度五特性评级（先盯谁）

指标冲击力 = **精确 × 时效 × 周期阶段 × 预测能力 × 关注度**

| 特性 | 判定 | 打分 1–5 |
|---|---|---|
| **精确** | 修订少、口径稳定 | |
| **时效** | 发布滞后短 | |
| **周期阶段** | 是否踩在本周期主场 | |
| **预测** | 是否能领先见拐点 | |
| **关注度** | 市场是否盯着它 | |

**周期法则**：衰退期**看量**（新屋开工、汽车销售）；过热期**看价**（CPI）。

**资产侧重**：债 → 就业 / CPI / PPI；股 → 就业 / ISM / 首申 / 零售；美元 → 贸易 / GDP / 经常项目。

**操作外壳**：五项各 1–5 分 → 按周期加权 → 每季复评，切换仪表盘。

**不适用**：学术研究、高频交易、把排名当永恒真理。

## 三、指标拼接与冲突仲裁

**一句话**：单指标是盲人摸象 —— 拼图要分层，冲突要仲裁，市场要裁剪。

| 层 | 内容 |
|---|---|
| 领先层 | 领先观察清单（PMI、首申、新订单、曲线利差等） |
| 同步层 | 就业、产出、零售 |
| 滞后层 | 通胀确认类 |

**仲裁次序**：**硬数据 > 软数据 > 轶事**；**拐点处反转**（拐点附近轶事与软数据先行）。

| 条款 | 内容 |
|---|---|
| 反直觉条款 | 心理 / 信心类指标只能作**证词**，不能作消费判决 |
| 轶事通道 | 褐皮书类定性材料：**可领路、不能定罪**（背景补充） |
| 市场裁剪 | 股票看需求端先行指标；债券看通胀与利率前景；汇市看美元驱动信息 |
| 国际纪律 | 外国指标与国内指标同等待遇：定期、关注、谨慎 |

## 四、收益率曲线倒挂

**一句话**：倒挂 = 市场写下的降息预告；最强先行指标也会误报 —— **一票即可，一票否决不行**。

| 项 | 内容 |
|---|---|
| 机制 | 期限利差 ≈ 未来政策路径预期 + 期限溢价；衰退预期 → 长端下穿短端 |
| 口径 | **10Y−3M 机制最纯**（近似"未来十年预期政策利率 − 当前政策利率"）；10Y−2Y 辅之；驼峰背离须登记 |
| 战绩 | 1970 年以来历次衰退前 10Y−3M 均倒挂，平均领先约 10–15 个月（二手转引） |
| 误报 | 2022–24 出现史上最长倒挂（537 个交易日，10Y−3M 近 −200bp 持续约两年），截至 2026 未衰退（二手转引） |
| 失灵原因 | QE 压平长端、全球负利率扭曲期限溢价等结构性力量 |
| 正确用法 | 衰退监测体系中的**一票** + 利率债情景触发器 + **预设误报退出条件** |
| 同类规则 | LEI 3Ds（六个月扩散指数 ≤ 50 且年化 < −4.3%）——领先指标不是水晶球 |

## 五、多资产交叉验证

判断一个读数是否"被市场确认"，看四类资产是否**同向印证**：

| 资产 | 印证什么 |
|---|---|
| 利率债 | 增长与通胀预期 |
| 汇率 | 相对增长与利差 |
| 商品 | 实物需求（螺纹、铜、油） |
| 权益 | 盈利预期与风险偏好 |

**同向 = 印证；背离 = 有一方在定价别的东西**（如流动性、政策预期），须点明，不得强行统一。

```
敏感度评级：精确 x / 时效 x / 周期阶段 x / 预测 x / 关注 x → 加权 <分数>
交叉验证：债 <同向/背离> ｜ 汇 <…> ｜ 商品 <…> ｜ 股 <…>
冲突仲裁（若有）：<硬> > <软> > <轶事>；拐点判定 <是/否>

```
