# 08 · 集成、取数通道与防撞

## 一、与两个 econ 技能的交接协议

| 对象 | 关系 | 本技能给什么 | 本技能要什么 | 红线 |
|---|---|---|---|---|
| `econpaper-architect` | 反向被调用（钩子式） | S2 资料盘点与 S7 数据节的**数据审计**：口径说明、可信度评级、时滞与修订纪律 | 指标语义需求、论文语境 | **绝不接管** D-2~D-7 的模型选型与识别策略 |
| `econ-math-mapper` | 管道前件 | L2 语义 JSON（四组必标 + 可追溯标注）+ 十项校验结果 | 映射结果回流校验口径 | **不替它判定**用哪个模型；不做计量估计 |

**触发接管的判据**

- 用户问题从"这个数怎么读"转向"用什么模型/怎么识别" → 交 `econpaper-architect`。
- 用户问题从"这个数怎么读"转向"怎么用数学表达" → 交 `econ-math-mapper`，并附上本技能产出的 L2 JSON。
- 两者同时需要 → 先出解读卡与 L2 JSON，再交给下游，不合并输出。

**实现方式**：独立成技能 + 钩子式调用，**不嵌入**对方文件内部（对方均有"不得改写既有阶段定义 / 铁律 / 硬阻断"的约束）。仅在对方 SKILL.md 的"外部 Skill 集成"或边界说明处**各加一行**指针。

## 二、取数通道（本技能不主动取数，只给通道）

用户问"现在 X 是多少"时，按序推荐并询问是否代取：

| 通道 | 适用 | 说明 |
|---|---|---|
| 官方一手 | 口径核验 | 国家统计局 / 央行 / 海关 / 财政部 / 外管局（中国）；BLS / BEA / BEA / Census / Fed（美国）。**口径与修订以官方为终审** |
| `finance-wscn-brief` | 最新读数 + 机构观点 | 行情接口 + 华尔街见闻 MCP 双路并行，适合"最新数据与市场反应" |
| ima 知识库 | 方法论原文 | kb_id `ehrOmGP5tNL1aooI-8Dm6GaSpQqpkk3SdsEWC2n9lyQ=`，专题书库 65 件（见 `books/_MIRROR_INDEX.md`） |
| `westock-data` / `neodata-financial-search` | 行情与财务数据 | 适合资产价格侧交叉验证 |

**纪律**：不得凭记忆填数值；无通道可取时，明确说"当前无法取数，以下按你提供的数值解读"。

## 三、防撞写法（触发词边界）

| 场景 | 归属 | 本技能动作 |
|---|---|---|
| 盯盘 / 选股 / 这只票 / 加仓减仓 / FVT | `a-share-fvt-watch` | 转出；若用户坚持，降级为条件式情景 + "非投资建议"标注 |
| 今天股市 / 行情 / 机构观点 / why did X move | `finance-wscn-brief` | 转出 |
| 美股走势 / 宏观解读（含取数） | `finance-wscn-brief` | 转出 |
| 写论文 / 识别策略 / DID / IV / 稳健性 | `econpaper-architect` | 转出 |
| 翻译成数学 / 这个想法用什么模型 | `econ-math-mapper` | 转出 |
| **指标解读 / 这个数怎么看 / 读数四问 / 预期差 / 口径辨析 / 数据打架** | **本技能** | 接 |

**本技能不做的四件事**：预测未来数值、给买卖建议、做计量估计、写论文。
