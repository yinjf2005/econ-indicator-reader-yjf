## 增补 SOP（投喂/训练扩展）

1. 新件先落 `books/_inbox/`（可直接粘贴 md，或用 `scripts/ingest_books.py --keyword <关键字>` 从 ima 拉取）。
2. 判层：属于「读/机制/预期/方法」哪一层 → 移入对应目录，文件名沿用 `<编号>_<主题>.md`。
3. 更新本文件：把该件状态由 `○` 改 `✔` 并填本地路径；新书则新增章节。
4. 若新件引入新方法，同步在 `../05-expectation-layer.md` 或 `../07-pitfalls.md` 增补条目，并在 `../00-guide-full.md` 版本记录注明。
5. 每次增补后跑 `python scripts/check.py --selftest` 确认 golden set 仍全绿。
