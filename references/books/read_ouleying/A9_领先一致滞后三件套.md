# 领先/一致/滞后三件套——思维模型档案

**归库**：经济理论模型库 › 专题-经济指标解读 › 《解读中国经济指标》-欧乐鹰
**适用场景**：预判经济拐点（拐头向上/向下）、区分"领先信号"与"事后确认"，避免用滞后指标做预测。
**核心原理**：经济指标按与周期的时差分三类——领先（提前 2–3 个月预示拐点）、一致（与当期同步）、滞后（事后确认）。欧乐鹰借 Conference Board 与 OECD 综合领先指标（CLI）框架，教读者用领先指标"抢跑"、用一致指标"确认"、用滞后指标"收尾"。
**来源**：欧乐鹰《解读中国经济指标》第6章（IMA 解析主源）＋ Conference Board/OECD CLI 公开方法（二手转引）｜ 蒸馏时间：2026-10-02
**Tags**：经济指标解读, 中国经济数据, 思维模型, 领先指标, 拐点预判, 周期分析

## 一、核心原理（R + I）
- **R**：书系统介绍领先/一致/滞后指标三分法，并点出 OECD 与 Conference Board 的"综合领先指标"（CLI）可提前数月捕捉转折。
- **I**：三件套清单——
  1. **领先指标**（提前 2–3 月）：新订单、PMI 新订单分项、M1/信贷脉冲、股市、房屋新开工、工业原材料价格、货币供应增速。
  2. **一致指标**（同步）：工业增加值、实际零售、发电量、税收、非农/城镇就业。
  3. **滞后指标**（事后 1–2 季）：CPI、部分口径失业率、利率、产成品库存、单位劳动力成本。
- **用法闭环**：领先转弱 → 预判拐点将至；一致指标随后确认下行；滞后指标最后"盖章"——忌用滞后指标（如 CPI）去预测拐点。

## 二、可迁移用法
- 做"拐点头寸"：领先组合（新订单＋M1＋PMI）连续 2–3 月走弱，提前减仓/避险；待工业增加值（一致）确认后再加确定性。
- 国际通用：CLI 框架适用于任何经济体，跨市场比较时用同一套分类避免"苹果比橘子"。

## 三、边界与误用
- 误用：盯着 CPI/库存（滞后）去"预测"经济见顶——它们只会事后确认，等你看到早已错过窗口。
- 边界：领先指标会"假摔"（如政策脉冲造成的 M1 波动）；须多指标共振，单一领先信号不足为凭（见 A1 怀疑框架）。
