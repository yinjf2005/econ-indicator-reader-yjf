## 四、第3章其余主要指标与第4章国际指标一句话要点

### 4.1 国内指标（二手转引逐条标注）

- **GDP**：现行BEA官方三版次=advance/second/third，逐版修正；著名案例：2008Q4初值-3.8%最终修正至-8.9%「二手转引·BEA公开修正记录」（→A5修正阶梯）。
- **零售额**：advance（先期）特性，初值噪音大；control组（剔除汽车/建材等）对应个人消费支出口径，比头条更能映射GDP消费分项「二手转引·Census零售贸易口径公开资料」。
- **工业产值与产能利用率**：产能利用率约85%被视作通胀压力警戒线「二手转引·美联储G.17口径/公开财经资料」（→A4四问之阈值问）。
- **ISM制造业报告**：50为荣枯线；⚠️权重沿革：第2版书稿载新订单30/生产25/就业20/供应商配送15/库存10，ISM官方自2001年起改为五分项等权各20%——使用现行等权口径并注明沿革「二手转引·ISM官方+百度百科口径考据（2026-10-02核验）」。
- **LEI（领先经济指数）**：现行判定规则为"3Ds"——六个月扩散指数≤50 且 六个月年化增速<-4.3%，两项同时满足方触发衰退信号「二手转引·Conference Board官网（2026-10-02核验）」；注意第2版书稿所载旧规则为"六个月累计降幅>2%且10个分项中多数下降"（库内英文2版PDF片段可证「库内PDF转述·英文2版LEI章」），"三连降"口径仍见于部分教材（→C2辨析⑤）。
- **新屋开工与营建许可**：许可为开工的先行审批变量；读数看独户而非多户，防单月波动误读「二手转引·Census/HUD公开资料」。
- **CPI**：核心CPI（剔除食品能源）vs 总CPI——总CPI含波动项，核心CPI是美联储判断通胀趋势的标尺，两者须组合阅读「二手转引·BLS口径/公开财经资料」。
- **PPI**：位于产业链上游，原材料价格先行于消费端物价「二手转引·BLS PPI口径」。
- **ECI（雇佣成本指数）**：曾为格林斯潘高度关注的通胀前瞻指标，工资型通胀的观测器「二手转引·公开史料（格林斯潘时期）」。
- **褐皮书**：定性轶事先行于统计数据；2007年10月褐皮书案例——定性语言先行捕捉到信贷紧缩向实体扩散「二手转引·美联储褐皮书档案/公开资料」。
- **FOMC会议**：约每六周一次、一年八次，为日历上最具影响力的固定事件；会前数据解读均以其为终点「二手转引·美联储官方」。

### 4.2 国际指标（二手转引逐条标注）

- **日本短观（Tankan）**：大型制造业DI（景气扩散指数）为核心读数「二手转引·日本央行官方」。
- **德国IFO**：约9000家企业调查，现况与预期两分项合成为商业景气值「二手转引·IFO官网口径」。
- **中国工业增加值**：规模以上工业企业口径（年主营业务收入2000万元及以上门槛），约占GDP三分之一，月度观测中国实体经济的核心变量「二手转引·国家统计局口径」。
- **OECD CLI**：复合领先指标，指示产出缺口拐点，领先约6~9个月「二手转引·OECD官方口径」。

## 五、行话术语中英对照表（库内第2章+第3章）

| 术语（中/英） | 一句话释义 | 出处 |
|---|---|---|
| 年率化（Annualized rate） | 将月/季环比折算为全年速率便于跨期比较，但会放大单月波动（0.1%月度波动→约1.2%年化） | 库内PDF转述·第2章 |
| 经济周期（Business cycle） | 产出、收入、就业等总体经济活动的扩张与收缩交替 | 库内PDF转述·第2章 |
| NBER（National Bureau of Economic Research） | 美国衰退起讫的事后裁定机构，拐点认定显著滞后 | 库内PDF转述·第2章 |
| 共识调查（Consensus survey） | 发布前对经济学家预测的汇总，构成"预期差"的基准 | 库内PDF转述·第2/3章 |
| 移动平均（Moving average） | 平滑周度/月度噪音的滚动均值 | 库内PDF转述·第2章 |
| 名义/实际/连锁美元（Nominal/Real/Chained dollars） | 名义=现价；实际=剔除通胀；连锁美元=链式指数剔除通胀的最新官方口径 | 库内PDF转述·第2章 |
| 修正（Revision） | 初值发布后基于更完整数据的常规更新 | 库内PDF转述·第2/3章 |
| 基准修订（Benchmark revision） | 定期的大规模口径重估，可能改写历史序列形态 | 库内PDF转述·第2章 |
| 季节调整（Seasonal adjustment） | 剔除日历与季节模式（现代程序如X-13ARIMA-SEATS/TRAMO-SEATS） | 库内PDF转述·第2章+二手转引·统计方法公开资料 |
| Lock-up（数据封锁） | 发布前在保密房间向持证记者提前提供数据、禁令解除前禁止外传的机制 | 库内PDF转述·第2章 |
| 家庭调查（Household survey） | 就业双轨之一：入户/家庭样本调查，产出失业率及U-1~U-6口径 | 库内PDF转述·第3章 |
| 机构调查（Establishment survey） | 就业双轨之二：企业薪资册调查，产出非农就业（覆盖约40万个企业地点，第2版口径） | 库内PDF转述·第3章 |
| 首申（Initial claims） | 首次申领失业保险人数，周度高频劳动力信号 | 库内PDF转述·第3章 |
| 四周移动平均（Four-week moving average） | 首申的平滑口径，抑制周度噪音与假期效应 | 库内PDF转述·第3章 |
| MLS（Multiple Listing Service） | 房源共享系统，二手房销售数据的数据源 | 二手转引·NAR口径/公开资料 |
| 核心PCE（Core PCE） | 剔除食品能源的个人消费支出价格指数，美联储通胀标尺 | 库内PDF转述·第3章 |
| 扩散指数（Diffusion index） | 报告"扩张/改善"成分占比的指数（改善×1+持平×0.5），50为荣枯线；ISM与LEI均用 | 库内PDF转述·第2/3章 |
| U-1~U-6（失业口径族） | 从长期失业（U-1）到广义不充分就业（U-6）的六档失业率，U-3为头条失业率 | 库内PDF转述·第3章 |

## 六、与其他知识资产的关系

1. **证券金融库·基本面分析子夹"指标体系与术语速查"**：本C1为其宏观侧对应物，术语口径互指（本表偏宏观发布机制，彼表偏公司财务指标）。
2. **曼昆宏观子夹**：C1中的GDP/CPI/失业率正是曼昆理论变量的观测载体——理论层（曼昆）→数据层（本书）→操作层（A系列模型）三层贯通。
3. **财经库·商品投研**：PMI/工业产值/PPI是商品价格链条的上游读数，商品投研可按A7拼接法引用本表做需求端验证。
